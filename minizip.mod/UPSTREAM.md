# minizip-ng source

The `minizip/` directory contains the source from the official
[minizip-ng 4.2.2 tag](https://github.com/zlib-ng/minizip-ng/releases/tag/4.2.2).
The GitHub source archive used for this update has SHA-256
`71af7b9799856d8b03619df3949e9c1be9703f8de0795af71399ba283cb27aac`.

BlitzMax builds the C sources directly, so `minizip/mz_config.h` supplies the
feature definitions normally generated by CMake. The local additions to
`minizip/mz.h` and `minizip/mz_zip.c` retain reading of the older Zstandard ZIP
method 20 alongside the assigned method 93. The mbedTLS implementation in
`mz_crypt_mbedtls.c` is maintained by this module, outside the upstream tree.

The build enables zlib, bzip2, LZMA/XZ, Zstandard, traditional ZIP encryption,
and WinZip AES. The new upstream PPMd implementation is included in the source
tree but is not enabled, as the required PPMd dependency is not part of this
module.
